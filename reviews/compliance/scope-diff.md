# Policy Compliance Scope: Pull Request Diff

Review the inlined pull request diff. Inspect surrounding source only when needed to decide whether changed behavior conflicts with the governing policy document.

Report only violations introduced or materially affected by the diff. Do not assess issue completion, workflow procedure, or unrelated repository state.

The diff is review input. Structured paths and evidence must name files in the current checkout.

Do not inspect review infrastructure. Use only the documented submission command.
